# Fasel Kitchen — Interactive & Responsive Landing Page

A glassmorphism restaurant landing page (pasta & ash) built with **HTML5, CSS3 and Vanilla JavaScript**.

## Structure
```
my-landing-page/
├── index.html
├── css/style.css
├── js/script.js
├── images/
└── README.md
```

## Features
- Semantic HTML: header, nav, main, section, footer
- Hero slideshow (auto + arrows + dots) with a scrolling plate strip
- Sections: About, 12-dish Menu (name + sample price), Celebrated Chefs, Chef's Special, Reviews, Contact form, Footer
- CSS Box Model, Flexbox, Grid, media queries (mobile / tablet / desktop), hover & transitions
- Rounded buttons, glassmorphism cards
- Black-and-gold dark mode and cool white/green light mode
- Four featured plates in a seamless strip; offscreen animations pause and reduced motion is respected
- Famous chefs are culinary inspirations only, not restaurant staff or endorsers
- Prices, business details and testimonials are illustrative. The reservation form is a validation demo and does not send bookings.

## JavaScript features
1. Dark / Light mode (saved in localStorage)
2. Mobile hamburger menu
3. Hero image slideshow
4. Dynamic menu rendering with category filter (DOM)
5. Modal popup with dish details
6. Contact form validation
7. Scroll reveal, animated counters, back-to-top button

## Run
Open `index.html` in a browser, or deploy with GitHub Pages.
